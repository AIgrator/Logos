Стенд проверки Vision-режима (Computer Use)

Каждая страница — один проверяемый навык. Дайте модели задание из заголовка страницы. Навигация сверху и кнопки «Далее» позволяют прыгать к любому тесту без перепрохождения.

  1. Drag-and-drop + цвета
    Перетащить маленькие блоки в большие того же цвета. Позиции случайны при каждой загрузке.
  2. Увод окна от клика
    Кнопка под окном Logos: полоска должна уехать, потом клик.
  3. Скролл
    Прокрутить длинную страницу вниз и нажать кнопку внизу.
  4. Нестандартные элементы
    Слайдер, крутилка (knob), переключатель, выбор цвета.
